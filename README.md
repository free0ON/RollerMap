# Роллеры — социальная сеть для роллеров

Android-приложение + сервер. Карты — OpenStreetMap (osmdroid), маршрутизация — OSRM (пешеходный профиль),
теги улиц — Overpass API, погода — Open-Meteo. Всё бесплатно, без API-ключей.

```
rollers/
├── core/    чистый Kotlin (JVM): вся предметная логика, общая для клиента и сервера, с тестами
├── server/  Ktor + Exposed (H2 по умолчанию, PostgreSQL через DB_URL), JWT, WebSocket
└── app/     Android: Jetpack Compose, osmdroid, Fused Location, TextToSpeech, foreground service
```

## Как функции из ТЗ реализованы

| # | Функция | Где | Как |
|---|---------|-----|-----|
| 1 | Маршрут на карте OSM со стороной улицы | `core/route/RouteGeometry`, `core/geo/Geo.offset`, `core/osm/OsmWays`, `app/ui/route/RouteBuilder` | Пользователь ставит точки → OSRM прокладывает путь по улицам → для каждой улицы Overpass даёт теги `sidewalk`, `cycleway`, `lanes`, `lit`, `surface` → автоматически выбирается сторона (с учётом направления линии OSM). Пользователь может переключить сторону (слева / по оси / справа), тип полотна и смещение. Ось улицы смещается параллельно на нужное число метров (с корректной обработкой углов), смены стороны становятся «переходами» и озвучиваются в навигации. |
| 2 | Качество покрытия | `core/surface/SurfaceQuality` | Экспертные оценки 1–5 с весом по уровню оценщика и затуханием по давности (полураспад 180 дней), байесовское сглаживание. Косвенная оценка по скорости: скорость участника на участке / его средняя скорость за заезд (медиана по заездам), что убирает разницу между новичками и профи. Если данных нет, начальная оценка берётся из OSM-тега `surface`. Возвращается достоверность 0..1. |
| 3 | Ремонты дорог | `server: /roadworks`, `RouteConditions.roadworksOnRoute` | Отметка долгим нажатием на карте (центр + радиус или полигон, срок действия), подтверждения другими участниками. Пересечение с маршрутом проверяется с шагом 10 м; участки с ремонтом попадают в предупреждения и в голосовые подсказки. |
| 4 | Осадки, ветер | `core/conditions/RouteConditions`, `OpenMeteo` | Почасовой прогноз сопоставляется с расчётным временем прохождения каждого участка. Ветер раскладывается на встречную и боковую составляющие относительно азимута участка. Отдельно учитываются недавний дождь (мокрый асфальт), порывы и риск наледи. |
| 5 | Освещение и светлое время | `core/conditions/SunCalc`, тег OSM `lit` | Высота Солнца по алгоритму NOAA → день / сумерки / темно на момент прохождения каждого участка. Считается доля пути в темноте по неосвещённым участкам; на карте такие участки рисуются пунктиром. |
| 6 | События | `core/event/EventPlanner`, `app/ui/events` | Средняя скорость, остановки (касание карты, притягиваются к маршруту), рекомендуемый уровень по скорости и длине, лимит участников, расчёт времени прибытия на каждую остановку и финиш. |
| 7 | Присоединение, навигация, трансляция скорости | `core/nav/Navigator`, `app/nav/RideService` | Пошаговые голосовые подсказки на русском («Через 150 метров поверните налево на …», переходы, остановки, ремонты, финиш), детектор схода с маршрута, сводка скорости каждый км, контроль графика события. Позиция и скорость транслируются участникам по WebSocket `/events/{id}/live`. |
| 8 | Запись результатов на сервер | `core/track/TrackStats`, `POST /activities` | Трек пишется в фоновом сервисе. На сервере выбросы GPS фильтруются (точность, скорость >70 км/ч), максимальная скорость считается по 5-секундному окну, средняя — только в движении. Скорости по участкам сохраняются и уточняют оценку покрытия. Отправка повторяется при сбое сети. |
| 9 | Рейтинг | `core/rating/Ranking`, `GET /leaderboard?metric=` | Отдельные таблицы по максимальной скорости, лучшей средней (заезды от 3 км), пройденному пути и общему баллу. Звания от «Новичка» до «Легенды», уровень катания растёт автоматически. |

## Сервер

```bash
gradle :server:run                       # http://localhost:8080, база H2 в ./data
DB_URL=jdbc:postgresql://localhost/rollers DB_USER=... DB_PASSWORD=... JWT_SECRET=... gradle :server:run
gradle :server:buildFatJar               # server/build/libs/server-all.jar
```

API (JSON; `🔒` — нужен `Authorization: Bearer <token>`):

```
POST /auth/register, /auth/login                    GET 🔒/me, 🔒/me/activities, /users/{id}
GET  /routes?bbox=s,w,n,e   GET /routes/{id}         POST 🔒/routes
GET  /routes/{id}/surface                            POST 🔒/routes/{id}/surface      {segmentIndex, score, comment}
GET  /roadworks?bbox=…                               POST 🔒/roadworks, 🔒/roadworks/{id}/confirm
GET  /events, /events/{id}, /events/{id}/plan        POST 🔒/events, 🔒/events/{id}/join   DELETE 🔒/events/{id}/join
WS   🔒/events/{id}/live?token=…  (LivePosition в обе стороны, только участники)
POST 🔒/activities  {routeId?, eventId?, points:[{point,time,speed,accuracy}]}
GET  /leaderboard?metric=OVERALL|MAX_SPEED|MAX_AVG_SPEED|DISTANCE
```

## Android

Нужны Android Studio / Android SDK 35 (модуль `app` подключается автоматически, если задан `ANDROID_HOME`
или `sdk.dir` в `local.properties`).

```bash
./gradlew :app:assembleDebug -Prollers.apiUrl=http://192.168.1.10:8080
```

По умолчанию `http://10.0.2.2:8080` — хост-машина из эмулятора. Экраны: карта маршрутов, конструктор маршрута,
карточка маршрута с прогнозом условий, события (создание, карточка, участие), заезд с навигацией, рейтинг, профиль.

Для продакшена: публичные OSRM, Overpass и тайловые серверы OSM имеют лимиты и правила использования —
при росте нагрузки нужен свой инстанс OSRM/Overpass и тайловый сервер (или коммерческий провайдер тайлов).

## Тесты

```bash
gradle :core:test :server:test
```

`core` — 21 тест: геометрия и смещение, переходы, покрытие, восход по NOAA, ветер, ночь + дождь + ремонт,
фильтрация трека, скорости по участкам, план события, правила участия, навигатор (манёвры, сход с маршрута,
голосовые фразы), рейтинг, разбор OSM/Open-Meteo.
`server` — 2 интеграционных теста: полный сценарий (регистрация → маршрут → оценки → ремонт → события
→ WebSocket live → загрузка заездов → рейтинг и повышение уровня) и запрет live-канала для не-участников.
